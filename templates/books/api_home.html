🛡️ JWT Authentication

🚦 Throttling

Anonymous and authenticated request limits are configured.

⭐ Example API Request

The API supports combining searching, ordering and pagination: 

GET /books/?search=Python&ordering=-price&page=2

Searches for books containing Python, orders them by price from highest to lowest, and returns page 2.
